# mpesa-analytics

Skeleton (CP0): guards, config, tooling and a probe page only. There is no product code yet.
All data in this repo is synthetic and generated by this repo.

## Setup

    uv sync
    npm ci                                  # ESLint and Prettier, dev only
    uv run python tools/vendor.py fetch     # pinned runtime, gitleaks and node, gitignored
    uv run pre-commit install

## Checks

    uv run pytest                           # guard tests; violations are planted in temp dirs
    uv run pre-commit run --all-files       # the fast checks; CI runs everything
    node tools/run_pyodide_tests.mjs        # imports the core under Pyodide

Guards print file names and counts, never matched text. See
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/CODING_STANDARDS.md](docs/CODING_STANDARDS.md),
[docs/glossary.md](docs/glossary.md) and [docs/decisions/](docs/decisions/).
