# Security

This repo must never hold real statements, phone numbers, receipts or passwords. Every
fixture is synthetic and regenerates from a seed in `fixtures/synthetic/MANIFEST.toml`.

## Reporting

Report a vulnerability, or real-looking data found in this repo, privately to the repo
owner. Use a GitHub private security advisory once the repo has a remote.

Do not paste the data into the report. Give the file path and a count. Do not attach a
statement, even a redacted one.
